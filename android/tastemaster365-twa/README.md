# TasteMaster 365 Android package

- Package: `eu.tastemaster365.twa`
- Host: `tastemaster365.com`
- Play launch URL: `/?platform=play`
- Upload key: `android.keystore`
- Private key details: `signing-key-info.txt`

Keep `android.keystore` and `signing-key-info.txt` together. Both files are
excluded from Git and are required for future Google Play updates.
